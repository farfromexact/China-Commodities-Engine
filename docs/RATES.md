# 国债期货与回购资金面

本模块已接入单次 Wind 入口、离线计划、校验、统一报告和 Chat 分片。**新增代码尚未完成本机 Wind 实机验收**；不因代码存在就宣称所有数据和权限可用。
只有用户明确启动后采集；不启用定时/登录任务、后台监控、远端工作流或其他仓库。

## 国债期货

覆盖中金所 TS（2年）、TF（5年）、T（10年）、TL（30年）。通过目标交易日 WSET `futurecc` 刷新目录，采集全部有效具体合约，不固定合约数量，不使用连续主力替代具体合约。
EOD 字段包括开高低收、结算、前结算、成交量、持仓量、成交额。程序生成主力/下一到期合约、同品种跨期价差和相邻交易日同合约持仓变化。

报价单位为每百元面值净价，**不是到期收益率**。TS每手面值200万元，TF/T/TL为100万元；点值分别20000/10000元。
没有CTD、转换因子、现金券和久期输入时，不计算IRR、CTD基差、DV01或跨品种风险中性套保比率。TS/TL价格相减不代表收益率曲线斜率。

普通日09:30–11:30、13:00–15:15；最后交易日仅上午。分钟截止时间沿用启动减5分钟、向下对齐5分钟边界，最后交易日合约单独封顶11:30，保留相对于统一截止时间的滞后；不发夜盘请求。
15:00–15:15启动仍可采国债分钟快照，不把未收完的时段当EOD。EOD按15:15判定，结算缺失仍失败，不保证该时刻Wind一定已发布。

输出：

- `data/treasury_futures/latest.json`、`snapshots/YYYY-MM-DD.json`：逐合约EOD及产品摘要。
- `data/treasury_futures/intraday/latest.json`、`intraday/YYYY-MM-DD.json`：独立延迟分钟快照。

## 回购面板

默认只取对报告有用的1、7、14天期限，共12条序列：

| 市场 | 序列 | 统计口径 |
|---|---|---|
| 存款类机构银行间质押回购 | DR001、DR007、DR014 | 日成交加权利率 |
| 全市场银行间质押回购 | R001、R007、R014 | 日成交加权利率 |
| 上交所通用质押回购 | GC001/GC007/GC014；204001/204007/204014.SH | 当日收盘年化回购报价 |
| 深交所通用质押回购 | R-001/R-007/R-014；131810/131801/131802.SZ | 当日收盘年化回购报价 |

银行间的 `DRxxx.IB` / `Rxxx.IB` 是待本机验收的显式Wind路由，不是已经验证的账户权限。首次采集用 `WSS sec_name` 核对名称/类型，拒绝把FR/FDR定盘利率或DR误当R；无法确认时记query_error，不猜代码或切换公开源。

WSD `close` 数值按配置的年化百分数口径原样保存，保留 `raw_value`、`rate_percent`、`unit`和单位依据，不按数值大小猜比例、不自动乘除100。**具体Wind路由、字段及单位仍待首轮实机确认**，产物限制字段保留此说明。
BP变化按百分数差乘100；读取前20个交易日的小时间序列，严格1/3/5/20日窗口中间缺日则该变化留空。
计算R001−DR001、R007−DR007、R014−DR014及DR007−DR001；GC001−DR001同时明确“交易所收盘报价vs银行间日加权利率”，不当作同口径套利。
回购利率不等于资金净流入流出，本轮没有央行公开市场投放/到期/净投放、Shibor或买断式回购数据。

交易所回购至15:30，本模块分钟快照仅覆盖这六条交易所序列，不把银行间日加权利率伪装成盘中报价。
15:30后、18:00前启动，分钟截止时间最多15:30。组合日终面板保守地在18:00后尝试，仍要求实际源日期等于目标日；不是供应商发布时间保证。

缺指标显式保留空值、错误和 `coverage_complete=false`，可随其他已验证数据发布，不能宣称面板完整。下一次用户启动再尝试缺项；同一次前台运行不对这些日期循环重试，不设置冷却或后台任务。
国债期货与回购分别按自身缺日计划补数，不因商品/股指已完整就跳过；收盘时间不同，模块日期可以合法不同。

输出：

- `data/funding/latest.json`、`snapshots/YYYY-MM-DD.json`：利率面板、BP变化、利差和缺失状态。
- `data/funding/intraday/latest.json`、`intraday/YYYY-MM-DD.json`：交易所回购分钟快照，非银行间EOD。

## 口径参考

- [中金所5年期国债期货交易细则](https://www.e-cffex.com.cn/u/cms/www/202007/08152340rnz2.pdf)：每百元面值净价、时段与最后交易日安排；实际合约上市/到期日期以Wind目录为准。
- [上交所交易业务指南（2026年8月）](https://www.sse.com.cn/lawandrules/guide2025/zqznlc/c/c_20260821_10829597.shtml)：通用回购时段、每百元资金到期年收益报价。
- [深交所回购代码与期限](https://investor.szse.cn/knowledge/bond/deal/t20180119_538891.html)、[交易制度](https://www.szse.cn/www/bond/introduction/traderule/repotrade/)：标准期限及15:30截止。
- [中国货币网定盘规则](https://www.chinamoney.org.cn/chinese/bkfrr/)：DR/R交易利率与FDR/FR定盘利率的区别。

上述定义不替代当前账号的Wind实机接口验收。
