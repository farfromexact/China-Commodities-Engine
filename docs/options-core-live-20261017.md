740条均可在旧版同日链找到对应准确合约。非空可比字段中：701个结算价、689个收盘价、674个成交量、701个持仓量全部一致。

701个IV可比值中85个变化，集中于GFEX的SI、LC、PT、PD、PS；701个Delta可比值中3个变化。不同采集时刻的供应商返回不能假定一致，现有证据不足以断言变化原因。

32个可比ATM IV摘要的绝对差平均为0.191875个波动率百分点，最大1.77个百分点。不能把这个差异全部归因于缩量：

- GFEX的供应商IV本身变化；同合约结算价不变并不保证供应商IV返回不变。
- 下述系列混组问题也改变了部分ATM的C/P组成。

## 信息损失和发现的问题

本次选中合约在旧版同日链中，覆盖已记录成交量的43.65%、持仓量的27.37%。这是按旧基准观测计算的保留比例，不把缺失持仓当作0，也不代表全市场真实份额。

新摘要可用ATM IV有32个分组，合格25-delta偏度有20个分组。旧链中与这些实际分组相对应的37个分组，原有33个非空ATM IV、31个合格偏度。单月平值核心样本不能代表完整期限结构、远月事件凸性或全链持仓分布。

**需要修正的选择器问题：** CF、OI、RM、SR的交易所目录在选择前缺少到期日。普通期权与带MS标记的月均期权被按相同标的、空到期日归组，再用“行权价→C/P”覆盖同侧条目。结果是月均Call与普通Put被选作配对；到期元数据随后补齐时，33个品种拆成37个分组。

| 品种 | 实际选中Call | 实际选中Put |
|---|---|---|
| CF | 11条MS，2026-11-11到期 | 11条普通，2026-12-11到期 |
| OI | 8条MS，2026-11-11到期 | 8条普通，2026-12-11到期 |
| RM | 12条MS，2026-11-11到期 | 12条普通，2026-12-11到期 |
| SR | 8条MS，2026-11-11到期 | 8条普通，2026-12-11到期 |

下游按真实到期日分开保存，因此没有将两种到期数据拼成一张完整曲面，但上游的“同一series成对采集”目标未达成。这39条MS Call缺少IV，也是本次IV覆盖率94.73%的直接原因。应在预算选择之前完成到期日/系列类型识别，并拒绝跨系列的同侧覆盖；不用扩大请求预算即可修正选择范围。

结论：大幅缩量与低门槛发布两项目标已被真实试跑验证；此测试版本仍需先修复四个品种的系列选取，并明确标的价格口径，再作为正式生产版本。
