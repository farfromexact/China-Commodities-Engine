## 2. 有效记录与分析能力分开

- 核心模式非空、同日期、来源及合约身份合法即可发布，不设整体成功品种比例门槛。
- 缺 IV 不阻断价格/成交/持仓。非法字段清空并记入 invalid_fields，其他有效字段仍保留；空、错日期记录不混入当日数据。
- ATM 必须同档两腿都有有效价格和IV；偏度须有合格25-delta两翼。未满足条件时指标留空，而不是仅把 readiness 标成 false 却继续输出数字。
- 保持全链曲面、全链持仓与执行能力不就绪；需要其他期限时显式下钻。
