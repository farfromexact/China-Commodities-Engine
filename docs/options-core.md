# 核心期权采集与低门槛发布

默认生产命令：

```sh
python scripts/collect_ifind_options.py --all-products --option-profile core --date YYYY-MM-DD --minimum-product-coverage 0
```

## 请求预算

- 全目录用于发现合约和挑选，不向 iFinD 请求全链再过滤。
- 每品种一个活跃标的/到期/系列类型组，优先普通期权，再按目录持仓、同日期货持仓、已有期权持仓及目录成交量排序。普通与月均（MS）期权不可配对或混组；元数据在选择前尽量补齐，OpenCTP 按日期在进程内缓存一次，缺到期日可保留价格但不声明分析就绪。
- 同日准确标的结算价用于定位 ATM；缺少时可用已存历史标的价定位，但历史价不会冒充当日估值输入。没有可信参考价则记录失败，不随意选中间行权价。
- 优先 ATM 成对 C/P，再保留已有 Delta 证据支持的25-delta两翼，其余预算取最近档位。合约预算仍为 `max(2, min(30, floor(目录合约数 × 10% / 2) × 2))`，小目录以一对合约为下限；最多15对。不为寻找两翼请求全链；历史 Delta 只用于选样，指标资格按新返回行情判断。
- 10个字段：latest、settlement、preSettlement、volume、openInterest、impliedVolatility、delta、gamma、vega、theta。不额外请求已存在的标的期货行情。
- 同日采集计划冻结，成功记录复用，只补尚未取得的合约；选择器版本改变时重建计划，防止复用旧版混组选样。`--force-refresh` 才重新请求计划内所有合约。新交易日重新选择。
- `--option-profile full` 为显式全链采集；默认工作流使用 core。

## 发布与用途

核心模式中，只要有一条结构有效、来源合格、源日期等于目标日的记录，即可发布最新链、质量说明与同日摘要。空结果不能覆盖最新有效数据。缺少 IV、OI、标的价、到期日、完整 C/P 或其他品种，不阻止已有合格记录发布。返回缺失/错日期的单个合约不会使整个品种报废；排除原因记录在采集计划中。

`universe_contract_count` 是成功品种计划内合约数；`quote_coverage_complete` 只指计划内返回完整。目录总数、实际选择数、复用数、请求数、拒绝原因另见 `collection_plans`。`full_chain_verified=false` 始终表明核心样本不是完整链。跨日旧数据保留在历史快照中，不拼接成同日链。

核心摘要无需等待高覆盖率或连续多日通过才发布；指标是否能用仍单独标记：

- `core_atm_ready`：有日期、到期日、标的，ATM 同档 C/P 两腿均有有效价格依据和 IV。单腿报价仍发布，但不冒充配对 ATM。
- `skew_ready`：C/P 的目标 Delta 均在 ±0.25 的0.05容差内，且日期与到期日有效；不以任意最近点代替标准25-delta。
- `surface_ready`、`positioning_ready`、`execution_ready`：核心样本均不宣称完整曲面、全链持仓或可执行盘口。
- 样本成交/持仓比率明确标为 `sampled_strikes`，缺失观测不按0加总。
- 一个月份样本不能支持期权期限结构；远期事件凸性、尾部、跨期或执行判断需要显式补充准确 series/合约。

## 下游提示词补充

> Options 使用核心采样摘要，数据发布与指标可用性分开判断。全品种初筛不受展示数量限制；优先读取品种/series的日期、采集范围和局部质量。未选月份和行权价不视为抓取失败。单月平值样本不外推完整期限结构、尾部或全链持仓；偏度缺少合格Delta点时留空。候选需要额外期限、准确合约或盘口时明确下钻需求，并遵守采集预算。发布成功不等于所有指标就绪。
